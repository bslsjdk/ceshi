# VN-Mobile — 持续运转的虚拟神经元波场（第一阶段）

1000 个虚拟神经元（VN）的持续循环：没有输入也在跑，输入是扰动，输出是当前状态快照。

## 结构

```
vn_mobile/
  core/neuron.py   VN 种群（SoA + CSR 邻接）、8-bit 量化
  core/update.py   单步更新方程（能量 / 状态 / 输出）
  core/group.py    相似同址的地址块布局与统计
  core/field.py    持续场：驱动主循环、计数器、快照
  io/encoder.py    输入 -> 扰动注入
  io/decoder.py    场 -> 快照读出
tests/test_neuron.py
main.py            一次性长跑入口
run_chunks.py      分块续跑（沙箱有单命令时长上限）
```

数据布局是扁平的 NumPy 数组，不含 per-neuron Python 对象，便于后续按 `float*` / `uint8*` 移植到 C++17 / Android NDK。

## 更新方程

```
g_i   = Σ_j w_ij · e_j · cos(φ_j - φ_i) · d_ij
e_i'  = (1-λ)·e_i + κ·tanh(g_i / √deg_i) + η
x_i   = I_i + (1/deg_i)·Σ_j h_j
h_i'  = α·h_i + (1-α)·tanh(W·x_i + b + B·A·x_i)
y_i   = s_i · h_i · e_i
```

第一阶段参数：`λ=0.05`、`α=0.9`、`η~N(0,0.001)`、度数 8、`mode=2(BACKGROUND)`、`health=16`、
适配器秩 `r=4` 随机初始化并冻结、相位冻结（规格未给 φ 的更新方程）。

## 运行

```bash
pip install -r requirements.txt
python -m pytest tests -q
python main.py --n 1000 --steps 1000000 --sigma 4.0 --kappa 0.047
```

## 三个必须上报的发现

### 1. 原参数（σ=0.1, κ=0.3）会让能量场死亡

`κ/λ` 是饱和天花板，`σ·κ ≳ 0.12` 是存活阈值。原参数落在阈值下方：实测 2 万步后
`e_mean = 9.6e-05`、`e_max = 0.0099`，能量衰减到噪声地板，场不再运转。
第一阶段demo参数改用 `σ=4.0, κ=0.047`。

### 2. 系统只有"死"或"炸"两种结局，无中间不动点

存活态的幅值等于天花板 `κ/λ`（实测 κ=1.0→20.0、κ=0.6→11.99，与 `κ/λ` 完全吻合）。
因此"活"且"e<0.95"只在 `κ ≤ 0.0475 且 σ ≥ 2.5` 的窄缝里成立。扫描数据：

| σ | κ | e_mean | e_max | 触顶% |
|---|---|---|---|---|
| 0.1 | 0.3 | -0.0000 | 0.0094 | 0.0 |
| 0.2 | 1.0 | -0.0080 | 18.83 | 40.9 |
| 0.5 | 0.3 | -0.0039 | 1.98 | 0.3 |
| 4.0 | 0.047 | 0.0181 | 0.9127 | 0.0 |

### 3. 状态层 h 无输入时必然归零

`h' = αh + (1-α)tanh(...)`，无注入时 `x=0` → 不动点在 0，实测 `h_max → 1e-11` 并继续衰减。
这本身可能是正确语义（波场常转、状态层待输入激活），但规格未明确。
另注意：h 衰减到 denormal 会让 NumPy 运算慢约 5 倍，代码里加了 `<1e-20` 归零保护。

## 待补规格

1. **φ 的更新方程缺失** — 目前相位冻结，干涉图样是静态的，无法体现"波扩散/共振"
2. **能量可为负** — `w` 均值 0 且 `tanh` 为奇函数，实测约 46% 节点 `e < 0`；规格里 e 是 8 bit 无符号 0-255，语义冲突
3. **h 的维度** — 规格写 `A[dim_in,r]`、`B[r,dim_out]`，但 `B·A·x` 要求 `A[r,dim_in]`、`B[dim_out,r]`；
   本实现按后者，并令 `h ∈ R^8` 以与方向向量维度一致
4. **单步耗时不可复现** — 同一配置在同一沙箱不同时段测得 337 / 1100 / 1700 µs/步，属环境波动，非代码差异
